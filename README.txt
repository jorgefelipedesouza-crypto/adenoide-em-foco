ADENOIDE EM FOCO — PROJETO INTERATIVO
========================================

Arquivos:
- index.html: página web completa, responsiva e pronta para publicação.
- banner_qr.pdf: modelo de banner em A4 paisagem com QR provisório.
- qr_provisorio.png: QR que aponta para um endereço-placeholder; substitua após publicar.
- bibliografia.txt: referências utilizadas.
- COMO_PUBLICAR.txt: passo a passo para colocar o site online gratuitamente.

IMPORTANTE SOBRE O QR:
O site está pronto, mas um QR Code só pode abrir a experiência pelo celular se a página estiver hospedada publicamente.
O QR incluído no banner é PROVISÓRIO e contém:
https://SEU-USUARIO.github.io/adenoide-em-foco/
Depois de publicar no GitHub Pages, gere/atualize o QR com o endereço real.
